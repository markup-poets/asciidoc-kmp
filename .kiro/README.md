# Historical design documents

These specs (`requirements.md` / `design.md` / `tasks.md` per feature) come from
the project's spec-driven origins in Kiro and are **kept as a historical record
only** — they are not maintained and large parts describe the pre-ASG
architecture (the legacy AST was removed in PR #43).

They remain useful for one thing: several `tck-quality-testing` tests cite
requirement numbers ("Validates: Requirements 2.1, 2.6") that trace back to the
`requirements.md` files here.

For current architecture and conventions see `CLAUDE.md`, `README.md`, and
`docs/`. The former `.kiro/steering/` instruction files were removed as fully
superseded by `CLAUDE.md`.
